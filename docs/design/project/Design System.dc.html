Usage rules
Primary 600 for buttons, links, focus ring, selected rows (primary 50).
Danger only for hard stops, expired, cancelled and destructive confirmation. Never for decoration.
Warning for near-expiry, pending approval and overridable checks.
Safety badge colors (Rx, Controlled, Quarantine, Hamper, Promotion) are reserved and never reused for other UI.
Money and quantities use neutral 900 at full opacity for maximum contrast.
